# Credit Risk Classification

R-based credit risk analysis project focused on distinguishing **good** and **bad** credit outcomes from financial and personal attributes. The work combines exploratory data analysis, statistical testing, visualization, and logistic regression to study factors associated with credit risk.

## Features

- Data cleaning and exploratory analysis in R
- Distribution and proportion visualizations
- Chi-square and proportion-based statistical tests
- Logistic regression for credit-risk interpretation
- Accompanying analysis report in PDF form

## Repository Contents

- `code.R` - main analysis script
- `Analysis.pdf` - supporting report/output document
- `README.md` - project overview

## Tech Stack

- R
- `dplyr`
- `ggplot2`
- `tidyverse`
- additional statistical/plotting libraries used inside `code.R`

## Notes

- The script currently references a local CSV path; update the dataset path in `code.R` before running it on another machine.
- Install the required R packages before execution.
